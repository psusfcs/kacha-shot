# 咔嚓截屏

悬浮球截图工具。**点球截当前屏，长按球自动滚动截长图**，截完一键三连：存相册 + 进剪贴板 + 跳转目标 App。

跟「全局AI助手」是两个独立 App，可同时安装（包名不同：`com.wentao.kacha`）。

## 它只干三件事

| 动作 | 说明 |
|---|---|
| **A 分享跳转** | 直接把图送进你指定的那个 App（微信/QQ/小红书…），在设置里选，能设默认 |
| **B 放剪贴板** | 备用通道。⚠️ 很多 App 不认剪贴板里的图片 |
| **C 存相册** | 兜底。存到相册的「咔嚓截屏」相册夹 |

三个动作是**同一下点击**完成的，不需要分别操作。

## 不做什么

- 不联网
- 不问 AI
- 没有聊天

## 用法

1. 装上后打开 App，按首页提示开三个权限：悬浮窗、截屏权限（无障碍）、悬浮球
2. 点首页的「导出目标」那一格，把想跳转的 App 加进来并设为默认
3. 之后任何时候：**点球 = 截当前屏**，**长按球 = 自动滚动截长图**

## 已知限制

- 分享是**新开一条会话**，接不上你之前的对话（这是系统的分享机制决定的）
- 剪贴板里的图片很多 App 不认，所以主力通道是"分享跳转"
- 相册会越攒越多，用不上随手删
- 无障碍权限首次要手动开；部分 ROM 会在重启后回收它
- 银行/支付类页面系统禁止截屏
- "无限下拉到底"的页面（如某些信息流）截不全，会截到一定长度停下

## 技术说明

- Kotlin + XML，minSdk 26 / targetSdk 36
- 全无障碍单通道截图（`AccessibilityService.takeScreenshot` + `dispatchGesture`），**不做 MediaProjection 降级**
- 长截图拼接：逐屏滚动 + 重叠区匹配缝合，拼不上就退回第一屏
- 依赖只有 core-ktx / appcompat / material / constraintlayout / lifecycle，无网络库、无数据库
- 全部 UI 图标手绘 vector，不用系统图标库
